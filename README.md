# schuelerfokus
Bootstrap-Website für Nachhilfe 
---
SchülerFokus ist eine persönliche Webseite, auf der Ian, ein Schüler des Leibnitzgymnasiums in Neustadt, Nachhilfe in Mathematik und Englisch anbietet. Die Seite stellt Ian vor, beschreibt seine Interessen und Qualifikationen, und bietet eine einfache Möglichkeit zur Kontaktaufnahme über ein integriertes Formular. SchülerFokus richtet sich vor allem an andere Schülerinnen und Schüler, die Unterstützung in den genannten Fächern suchen und Wert auf regelmäßige, individuelle Nachhilfe legen.
